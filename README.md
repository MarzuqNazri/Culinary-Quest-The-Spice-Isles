# Culinary Quest: The Spice Isles

A small original 2D top-down adventure RPG built with Phaser 3. It takes inspiration from the broad genre conventions of classic creature-collecting adventures, while using original characters, setting, names, and visuals.

## Play
- Open `index.html` in a browser with an internet connection (Phaser 3 loads from jsDelivr).
- Move with **WASD** or **arrow keys**. Press **E**, **Space**, or **Enter** to interact.
- On touch devices, use the on-screen directional buttons and **A** interaction button. Tapping around the playfield also moves in that direction.
- Talk to Chef Mira to choose a starter Spice Spirit.
- Walk through grass to encounter wild Spice Spirits.
- Battles are turn-based: use a Spirit Move, throw a Spice Seed to befriend a wild spirit, or answer a Culinary Quiz.
- Visit the Culinary Guild to start a trial and earn Guild Marks. Talk to Ranger Nasi for another Spice Seed.
- Use the Music button to toggle the original generated chiptune-style melody. Audio starts after a user gesture, as required by browsers.

## Publish with GitHub Pages
Upload `index.html`, `main.js`, and `README.md` to the root of a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`.

## Notes
- The game uses generated shapes, emoji, and code-generated sound; no external image or audio assets are required.
- This is a playable prototype. Save/load, a larger map, a quest journal, more battle animations, and comprehensive mobile testing would be sensible next upgrades.
- Culinary questions are original and intended for practice. Verify food-safety answers against your local regulations before using for formal assessment.
